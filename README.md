## Clara

Clara is a WIP experimental statically-typed FP/OO programming language that compiles to JavaScript.

It's (at least for now) just a personal learning project.

### AI usage

All code up to April 2026 was written by hand. Going forward, AI tools (such as GitHub Copilot) may be used to assist with some changes (especially mechanical refactorings, test maintenance, documentation). Any AI-assisted code is reviewed, understood, and often edited before being committed.
